ARCHITECTURE DECISIONS (FIXED — WILL NOT CHANGE):
├── STT:    Faster-Whisper (self-hosted on EC2) — NOT cloud Whisper API
├── LLM:    Ollama (self-hosted on EC2) — NOT Groq/OpenAI cloud API
├── TTS:    Piper TTS (self-hosted on EC2) — NOT Azure/Google TTS
├── VAD:    Silero VAD (client-side ONNX) — reduces server load
├── DB:     PostgreSQL (NOT SQLite for production 10K users)
├── Cache:  Redis (rate limiting + idempotency)
└── Auth:   JWT-based (replace "local-user" placeholder)
